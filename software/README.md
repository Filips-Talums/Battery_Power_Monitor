# Software

The software is kept in project-stage folders so working historical checkpoints remain available:

- [Breadboard prototype V1](breadboard-prototype-v1/) is the stable calibrated breadboard firmware.
- [Perfboard prototype V2](perfboard-prototype-v2/) is the firmware associated with the perfboard build.
- [`platformio/`](platformio/) contains the earlier `Supply_Power_Monitor` and `Supply_Power_Monitor_TEST` PlatformIO projects.
- [`pseudocode.txt`](pseudocode.txt) contains the early software design outline.

Each firmware project is self-contained and should be opened from its own directory in PlatformIO.
