# KiCad Designs

This directory preserves the project's KiCad design history and manufacturing files:

- `Power_Monitor_V1/` contains the first PCB design.
- `Power_Monitor_V2/` contains the version 2 project, its libraries, 3D model, and tracked recovery material.
- The top-level `Power_Monitor_V2.1.kicad_*` files contain the later version 2.1 board project files.
- `PCB_V2_PRINTING/` and `PCB_V2_PRINTING.zip` contain version 2 manufacturing outputs.

Recovery and historical files are intentionally retained. Open the version matching the project stage you want to inspect.
